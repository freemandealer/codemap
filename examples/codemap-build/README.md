# CodeMap · 从已验证地图到离线 HTML

这是读取 CodeMap 实际 TypeScript 源码后编写的地图。仓库根目录运行 `npm run demo`，打开 `artifacts/codemap-build/map.html`；本说明随产物交付时，直接打开同目录 `map.html`。

推荐路线：主题 → 构造离线候选 → buildHTML → 内嵌数据与运行时 → 原始代码。

地图包含 3 个源码文件、18 个讲解节点、7 个实体、10 条调用关系、2 条局部流程、14 条证据和 11 个源码片段。回答 build 子命令如何匹配验证收据、构造候选、检查内容并写入文件，同时保留 `--repo` 可选复核、预算失败和异常出口。

源码指纹、行号和片段已经机器核对；解释按 CodeMap Skill 的质量标准核对了直接调用点、导入绑定、条件与错误路径。尚未完成浏览器目视检查和独立读者试用，因此这是候选阅读样例。它不解释完整 CLI、布局算法、浏览器事件或 Linux VFS。

两条关键边界：收据是内容匹配记录，不是签名；CLI 依次写构建收据与 HTML，两个文件不是一个事务。第二次写入发生 I/O 故障时可能产生新收据与旧 HTML，应以 `inspect` 读取 HTML 内嵌清单判断实际版本。

地图固定的是当前三个源文件的内容快照。修改源码后验证会失败，需要重新阅读并更新地图，不能只改指纹。`validation.json` 记录源码核验，`build-receipt.json` 记录产物指纹。

分享时将 HTML 放到自己的静态站点，再用阅读器的分享按钮取得节点链接或 iframe 示例。`file://` 路径不能用作公网链接。HTML 包含已选取的原始源码。
