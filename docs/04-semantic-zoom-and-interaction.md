# 04 · 语义缩放与交互详细设计

## 1. 阅读界面

```text
┌ 标题 / 阅读目标           搜索      缩放 - +   全图   分享 ┐
│ 主题 > 模块 > 机制 > 当前函数                             │
├──────────┬──────────────────────────┬───────────────────┤
│ 文本大纲 │                          │ 说明 / 关系 / 证据 │
│ 可折叠   │   可平移、缩放的地图      │ 输入与输出         │
│ 键盘入口 │   当前焦点 + 周边概览      │ 条件与不确定性     │
│          │                          │ 源码原文及行号     │
├──────────┴──────────────────────────┴───────────────────┤
│ 图例 · 关系类型 · 当前范围 · 仍未展开 / 未确认的内容       │
└────────────────────────────────────────────────────────┘
```

主地图承担空间导航；详情栏承担较长文字和完整代码阅读。核心代码在最细地图尺度也可见，但不要求把长函数所有行挤进一个节点。读者可以打开代码阅读面板继续查看本图已内嵌的上下文。

桌面详情栏建议宽 360–480px，可关闭。窄屏使用底部面板和文本大纲，地图只在主动进入探索后接管手势。

## 2. 三个相互独立的概念

- **相机缩放**：连续改变坐标映射，`screen = world × k + translation`。
- **层次展开**：决定一个区域显示摘要还是显示子区域。
- **内容密度**：同一节点依屏幕面积显示标题、摘要或完整步骤/源码。

不设置“全图 z=3 时所有节点都必须是函数”。分支深度和节点占地不同，采用局部区域的实际屏幕尺寸触发展开。同一画面可同时看到展开的路径解析步骤与周边的权限模块概览。

## 3. 布局与相机

每个节点在父内容区有固定矩形；展开时子节点已经存在于该区域，不在手势中重新计算全图布局。父标题和边框可保留作为定位背景，但不再显示与子节点重复的摘要卡。

缩放围绕指针或双指中心保持锚点：先求锚点对应世界坐标，再更新比例和平移，使锚点落在同一屏幕位置。选择“进入”时平滑 fit 到目标区域；选择“上层”时 fit 到父区域并恢复合理概览。

深层地图采用父局部坐标。当尺度导致精度下降时把焦点祖先设为相机坐标原点，保留逻辑位置和上层历史。视口变化重新计算 fit，不改变语义层次和数据 ID。

## 4. 展开规则与防抖

编译器为每个可展开区域计算最低展开宽高，基于子节点的数量、排布和最低可读尺寸。以下为原型默认值，属于可调配置：

| 项目 | 初始建议 |
| --- | --- |
| 摘要主体最小可读尺寸 | 160×88 CSS px |
| 普通区域最低展开参考 | 360×220 CSS px；子节点多时由布局提高 |
| 代码主体推荐尺寸 | 至少 520×260 CSS px；否则打开详情或进一步聚焦 |
| 展开阈值 | `D = min(projectedWidth/minExpandWidth, projectedHeight/minExpandHeight) ≥ 1` |
| 收起阈值 | `D ≤ 0.8`，形成滞回，避免临界抖动 |
| 手势细节更新 | requestAnimationFrame；连续 120ms 满足阈值后提交层次切换 |
| 展开过渡 | 180–240ms；减少动态效果偏好下即时切换 |

只评估与视口及预加载边距相交的候选区域；同屏超预算时，优先保留焦点路径及主关系，其他区域保持摘要。根概览可初始化为“根已展开、主要职责可见”。自动展开与显式进入用相同状态机，显式进入可先 fit 到足够空间。

同一次渲染状态中，某个区域要么作为折叠摘要，要么展开为子区域。视觉淡入淡出期间可以同时画两层，但命中测试和关系成员在切换点只归属一套逻辑状态，不能重复计算。

## 5. 可见前沿与关系投影

`Frontier` 是按当前展开集合对讲解树作出的一个切面：从根向下，未展开的节点成为前沿，已展开的节点递归到子节点。渲染时再做视口裁剪；裁剪不能改变图的语义归属。

展开容器还有自己的边界端口。这点很重要：一个关系只确认了“函数 A 调用 B”，未确认 A 的哪个内部步骤时，即使 A 展开了，也只能连到 A 的边界，不能随便指向第一个子步骤。

端点投影规则：

```text
resolveEndpoint(entity, optionalPort, view):
  origin = port.detailNodeId 或 entity.canonicalNodeId
  若 origin 或它的某个祖先处于折叠前沿：
      返回最近的折叠前沿节点（当前状态下至多一个）
  否则 origin 已展开：
      返回 origin 容器的自身边界端口
```

对每个原子 Relation 各投影一次端点，然后按下列键分组：

```text
(sourceRepresentative, targetRepresentative,
 sourceVisiblePort, targetVisiblePort, type, direction, claimStatus, role)
```

在粗尺度，隐藏的细端口统一投影为该区域边界端口；在细尺度，已显示的接口/调用点分别出现。因此一个 `A → B（调用 × 3）` 可以自然拆成 `a1 → b1`、`a1 → b2`、`a2 → b2`。若只展开 A，得到 `a1 → B（×2）` 与 `a2 → B（×1）`。

每条聚合边携带 `memberRelationIds`，数量是 ID 集合大小。详情栏显示每个成员的条件、证据和不确定性。不同类型、方向或事实状态默认不合成同一条线；视觉上共享通道也必须分轨并可分别命中。

若关系两端映射到同一个折叠模块：

- 不同实体之间的关系进入模块“内部关系 n 条”徽标，放大后恢复。
- 同一实体的真实递归可显示回环并标记递归，不能被当作噪声删除。
- 原子实体关系与步骤 Flow 分开统计，不把同一解释的不同图层误加总成调用次数。

局部 Flow 从它的 fromNodeId/toNodeId 直接执行同样的节点投影，不经过 Entity 的规范位置。只有 ownerNodeId 的区域已进入当前阅读范围时绘制流程；收起后计入该区域的局部流程摘要。Flow 按所属区域、投影端点、kind 和分支标签分组；不同条件不合成一条没有条件的箭头。

## 6. 数量守恒与密集图

每一条原子关系在当前状态下恰好属于一个桶：绘制的聚合边、模块内部关系、被用户过滤的关系、完全位于视口外的关系，或因显示预算进入的显式折叠组。桶之间不重叠，ID 并集等于全部 Relation ID。

这给出了可自动测试的不变量。成员不能因端点展开、别名出现、缩放动画或预算裁剪而丢失、复制。聚合关系的线宽可按 `1 + log2(1 + count)` 缩放并设上下限；图例明确表示“已建模关系数量”，不暗示流量或性能。

跨视口边在画布边界显示方向提示，点击可定位目标。大量接口保留精确计数和成员列表，默认强调当前选中的关系和主路径，其他关系降低对比度。超预算不得随机删边；需要稳定排序并显示剩余数量。

## 7. 手势、键盘与嵌入模式

| 操作 | 独立页面行为 |
| --- | --- |
| 普通滚轮 | 鼠标位于地图且不在滚动面板时，围绕指针缩放 |
| 触控板双指捏合 | 缩放；双指平移行为通过输入适配器处理 |
| 触屏双指 | 捏合与平移；只在地图探索区域接管 |
| 拖拽空白 | 平移；节点正文允许文本选择 |
| 单击节点 | 选中并展示详情，不突然改变尺度 |
| 双击节点 / 进入按钮 / Enter | fit 该节点并展开一层；无子层则读代码 |
| `+`、`-`、`0` | 放大、缩小、适配全图；输入框内不接管 |
| Escape / 上层按钮 | 先关闭当前弹层；再次返回父层 |
| `/` | 聚焦搜索；文本输入中保持原行为 |

普通滚轮在触控板上的平移/缩放偏好提供显式模式切换，避免依赖不可靠的硬件识别。浏览器的 wheel 事件存在单位、可取消性及缩放修饰键差异，输入层需归一化并实测。[MDN wheel 事件](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event)

**iframe 默认不接管博客页面滚动**：显示“点击探索地图”，进入后地图处理手势，Escape 或退出按钮归还页面；工具栏始终可用。代码详情区的滚轮优先滚动代码，不能意外缩放背景。不要全局禁止浏览器页面缩放。

实现采用统一缩放适配器，避免同时注册两套捏合处理造成一次动作缩放两次。`preventDefault` 只用于明确接管且可取消的地图事件；必要的非 passive 监听限制在地图表面。

## 8. 搜索、导航与深链接

搜索匹配标题、摘要、符号名和路径；源码全文搜索后置。搜索结果包含完整讲解路径。选中结果时展开祖先、fit 到节点并保留返回历史；搜索只是导航，不能修改地图事实。

建议 URL 状态：

```text
map.html#v=1&map=minifs-open&node=n-open&detail=code
map.html#v=1&map=minifs-open&relation=r-open-lookup
```

优先存语义 ID，不把像素相机当唯一状态。跨尺寸打开时根据节点重新 fit。状态优先级为：合法 relation → 合法 node → 根概览；不认识的版本/参数忽略并给简短提示，失效对象回到根，不能空白。

只有显式进入/返回等导航写入浏览器历史；手势停止后可 replace 当前状态，避免一次滚动产生几十条历史。分享链接只包含定位状态，代码数据仍在对应 HTML 里；`file://` 地址不能变成别人可访问的公网 URL。

## 9. 可访问性与视觉语义

标题和说明保持屏幕可读字号，不能随着几何缩小到不可读；面积不足时降为摘要/标签。源码保留等宽字体、行号和可选择文本。可见焦点、选中状态、推断与未知同时用文字/图形说明，不仅依赖颜色。

同步文本大纲提供完整语义层次，支持 Tab、方向键和 Enter；屏幕阅读器不需要理解 SVG 连线才能完成阅读。展开后焦点移入目标标题，收起前先将焦点移到仍存在的祖先，防止焦点丢失。

所有 hover 才能发现的功能都有点击或键盘等价入口。Reduced motion 关闭过渡动画，仍保留层次变化；触控目标建议至少 44×44 CSS px，邻近端口可通过关系列表选择。
