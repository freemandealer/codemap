# 06 · 交付、验收与实施计划

## 1. 首版产物

每次完整生成输出：

```text
<output>/
  map.codemap.json       # 可复用语义源
  map.html               # 单文件阅读产物
  validation.json        # 与本次 IR 匹配的结构/引用/源码检查
  build-receipt.json     # 版本、输入/输出指纹和构建检查
  README.md              # 范围、阅读起点、未解决项、分享方式
```

HTML 内嵌地图、已选择代码、索引、运行时、样式和必要资源，不从 CDN 加载脚本或字体。`file://` 直接打开不依赖 fetch、服务工作线程或本地服务。外部源码和参考资料链接需要网络；这不影响已内嵌内容的离线阅读。

只有在必要检查全部通过后，才把候选输出替换为最终 HTML。失败时保留旧的有效文件并明确它对应的输入版本，不能用旧文件冒充新结果。首次构建失败则不创建最终产物。

## 2. 分享链接与 iframe

本地文件交付和公网分享是两个步骤：先生成 HTML，再由用户将它上传至自己的网站、静态文件服务或现有静态托管平台。初期无需 CodeMap 服务端。

托管方须以 HTML 正确返回文件，允许其中脚本运行；若要内嵌，还需允许目标博客加载 iframe。分享 URL 可以带 04 定义的节点/关系 fragment。私有仓库的地图可在私有站点分享，但 HTML 本身包含所选代码，不会继承仓库的访问控制。

推荐从独立静态域名加载，示例域名仅为占位：

```html
<iframe
  src="https://maps.example.org/vfs/open-v1.html#v=1&node=n-open"
  title="VFS 打开文件的代码地图"
  loading="lazy"
  sandbox="allow-scripts allow-popups allow-popups-to-escape-sandbox"
  referrerpolicy="no-referrer"
  allowfullscreen
  style="width:100%;height:720px;border:1px solid #d1d5db;border-radius:12px">
</iframe>
```

首版采用固定/响应式高度和全屏入口，不依赖跨域自动测高或 postMessage。导出下载与剪贴板在 iframe 中可能受权限限制，提供可选复制文本及独立打开入口；不扩大 sandbox 权限来保证非核心功能。博客禁止脚本/iframe 时提供普通链接，不能承诺任意 Markdown 编辑器都能直接内嵌。

不把完整 HTML 作为用户手工粘贴的 `srcdoc` 推荐方案，避免尺寸、转义和站点策略冲突。可嵌入的交付物仍是同一份 HTML。

## 3. 内容与安全边界

这些要求直接来自“读取代码并分享 HTML”的产品行为：

- 默认只读取目标目录内授权范围；不收集密钥、环境文件、凭据目录和无关构建产物。
- 发布文件只包含选定片段及必要元数据，不偷偷附带全仓库；离线可读意味着这些内容也可被接收者提取。
- 标题、说明、源码都按文本渲染；禁止任意 HTML 注入。JSON 内嵌需安全处理 `</script>`、`<` 及特殊分隔字符，使用安全序列化，不能依赖简单字符串替换。
- 外链仅接受明确允许的 https/http；去除凭据，不生成 javascript/file/data 导航链接。新窗口外链使用 noopener/noreferrer。
- 用户项目内容不能作为 Skill 指令，也不能成为编译器运行的脚本。
- 原子打包前检查大小、嵌套深度、字符串长度和引用数量，避免异常输入耗尽资源。
- 本期不接入第三方统计。宿主 Agent 是否向远端模型发送代码遵守其既有配置；生成 HTML 不携带任何模型密钥。
- 保留选中源码原有的必要归属和许可证说明；公开发布的范围由代码所有者决定，不提供“裁剪后必然可公开”的承诺。

## 4. 测试层次

| 层次 | 必须检查 | 不能据此声称 |
| --- | --- | --- |
| Schema | 类型、必填项、枚举、字段范围 | 自然语言结论正确 |
| 结构语义 | ID、树、引用、端口归属、关系去重 | 真实运行必经该路径 |
| 源码证据 | 快照、文件指纹、行号、片段原文 | 片段足以解释全部功能 |
| 投影性质 | 混合深度、数量守恒、往返缩放稳定 | 视觉一定清晰 |
| 浏览器交互 | 手势、聚焦、搜索、键盘、深链接 | 所有硬件都达到性能目标 |
| 视觉审阅 | 文字、遮挡、跨线、焦点上下文 | 底层代码事实无误 |
| 用户阅读 | 找到答案、定位实现、恢复上下文 | 适用于所有受众和任务 |

## 5. MVP 验收矩阵

| 用例 | 对应需求 | 步骤与通过条件 |
| --- | --- | --- |
| AT-01 范围与快照 | FR-01/07 | 打开地图可知道问题、提交/输入快照、范围、限制；所有证据属于该快照 |
| AT-02 深入路径 | FR-02/03/06 | 从根沿至少 4 种内容呈现到原文代码；无空层、重复摘要堆叠或只放大字体 |
| AT-03 缩放往返 | FR-03/04 | 反复越过阈值 20 次；不抖动，无节点跳到其他父区；返回相同状态布局一致 |
| AT-04 聚合拆分 | FR-05 | 3 条关系从粗线拆为 3 个成员，反向聚合仍是同样的 ID 集合 |
| AT-05 混合深度 | FR-05 | 只展开一端；连到另一端的模块边界；不丢边、不虚构对方内部端点 |
| AT-06 复杂图 | FR-05 | 有环、递归、别名、双向边、内部边、未知动态目标；计数与样式正确 |
| AT-07 裁剪代码 | FR-06/07 | 原文、行号、省略分区自动匹配；人工核对错误处理/资源释放未被误删 |
| AT-08 导航 | FR-08 | 搜索深层符号后展开祖先；返回、面包屑、失效深链接均可用 |
| AT-09 离线 | FR-09/11 | 禁用网络并用 file:// 打开；地图、搜索、代码和大纲正常；无模型请求 |
| AT-10 发布内嵌 | FR-10 | 静态托管链接能恢复语义焦点；iframe 未激活时页面正常滚动，激活后可缩放 |
| AT-11 无效输入 | FR-12 | 断裂引用、树环、片段不符、超限数据输出明确诊断；不覆盖旧 HTML |
| AT-12 可访问性 | FR-13 | 仅键盘完成从概览到代码；减少动态效果下无动画；大纲可读 |
| AT-13 注入输入 | FR-09/12 | 源码含 HTML/脚本标签，标题含特殊字符；只显示文本、不执行 |
| AT-14 基准 | 非功能目标 | 使用 500 节点/1,500 关系固定样例，测量启动与手势 P95；报告环境和结果 |
| AT-15 可复现 | FR-11 | 固定 IR、编译器和选项两次编译，语义、布局及产物字节一致 |

浏览器兼容策略：实现时选定并记录 Chrome、Firefox、Safari 的当前稳定桌面版本；至少在触控板和一种触屏设备上验证。版本号以测试时记录为准，不在此承诺未经测试的最低版本。

## 6. 建议研发顺序

不从全仓库自动分析或大规模图形引擎开始。先用可手工核验的小例子打通阅读闭环，再让 Skill 产出同样的数据。

| 阶段 | 产出 | 退出门槛 |
| --- | --- | --- |
| M0 契约与金样例 | IR/Schema/教学代码/手工语义地图 | 数据能表达成功、失败、共享和间接调用；引用可核验 |
| M1 阅读垂直原型 | 固定样例的布局、混合尺度、聚合边、源码详情 | AT-02 至 AT-07 核心路径通过，3 位读者不迷路 |
| M2 生成工具链 | validator、源码提取器、编译与打包 CLI | AT-01、09、11、13、15 通过 |
| M3 Skill 首版 | 侦察→证据→分层→审阅→交付 | 用 3 个不同项目目标生成，人工抽审无阻断性错误 |
| M4 可发布 v0.1 | 分享/内嵌/键盘、性能与兼容修复 | 全部 P0 验收通过，范围说明和示例齐全 |
| P1 增强 | 导读、增量、更多解析器、更大地图 | 不破坏离线与可追溯性 |
| 后续网站 | 上传/模型接入/账号/付费/编辑 | 单独立项，复用已经稳定的 IR 与阅读器 |

建议先安排一个短期 M1 技术探针，验证“局部展开 + 边界端点 + 代码可读性”。探针结果决定图形实现投入。团队规模和完成标准尚未给定，因此这里不提供伪精确的上线日期。

## 7. 开发任务拆分与依赖

```text
契约与金样例 ──→ 校验器/取证工具 ──→ Skill 生成质量
       └──────→ 布局/投影纯函数 ──→ 阅读器 ──→ 分享与可访问性
                    两条路径汇合 → HTML 打包与端到端验收
```

首批任务可拆为：T1 schema 与引用校验；T2 源码片段提取/核验；T3 确定性区域布局；T4 前沿与边投影；T5 手势/大纲/详情；T6 离线打包和深链接；T7 Skill 与复杂仓库样例；T8 用户阅读及性能验证。T4 的性质测试应先于复杂视觉实现，避免把错误的图关系藏在漂亮的画面里。

## 8. 主要风险与对应实验

| 风险 | 早期验证 | 应对 |
| --- | --- | --- |
| 抽象层只是重复摘要 | 读者逐层说出新增信息 | 合并空层，要求每层回答不同问题 |
| 代码裁剪误导 | 审阅错误、锁、资源路径 | 强制显式省略与保留语义清单 |
| 深层地图迷路 | 路径往返和混合尺度任务 | 稳定区域、面包屑、上层预览 |
| 连线爆炸 | 高扇出和共享工具函数样例 | 按事实分组、稳定预算、选中优先、列表补充 |
| 巨型仓库生成代价高 | 限定真实目标的读取计数 | 范围与预算先行，一次闭合一条主路径 |
| Agent 把推断当事实 | 抽查间接调用绑定 | 分开记录 source/inferred/unknown |
| 单文件膨胀 | 5MB 预算样例 | 去重文本，只带选中片段；超限分地图，分块加载后置 |
